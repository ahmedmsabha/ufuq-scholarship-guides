## الدول المغطاة

- **كتب مخصصة:** بريطانيا، هولندا، إيطاليا، إسبانيا، فرنسا، ألمانيا، إيرلندا.
- **كتاب أوروبا (8):** المجر، تركيا، بولندا، التشيك، سلوفاكيا، النمسا، سويسرا، السويد، النرويج، الدنمارك، فنلندا، بلجيكا، لوكسمبورغ، رومانيا، بلغاريا، صربيا، سلوفينيا، كرواتيا، اليونان، قبرص، البرتغال، مالطا، ليتوانيا، لاتفيا، إستونيا، روسيا، إضافة إلى المنح الأوروبية العابرة للدول.
- **كتاب المنح الحكومية (9):** اليابان، كوريا الجنوبية، الصين، هونغ كونغ، روسيا، تركيا، كازاخستان، أذربيجان وآسيا الوسطى، ماليزيا، الهند، تايوان، باكستان، إندونيسيا، سنغافورة، فيتنام، البرازيل، قطر، والمنح العربية والإسلامية.
- **كتاب (10):** كندا، أستراليا، الولايات المتحدة.

## ماذا في كل كتاب؟

1. **المنح** العامة (من خارج الجامعات) ومنح الجامعات.
2. **الجامعات والتخصصات** واحدة واحدة.
3. **الأوراق المطلوبة** مع **نماذج جاهزة**: سيرة ذاتية، خطاب دافع، رسائل بريد، رسائل توصية.
4. **الجدول الزمني** نحو القبول في سبتمبر 2027.
5. **التأشيرة والخروج من غزة** حيثما انطبق.

## تنبيه

المنح تتغير مواعيدها وشروطها باستمرار. الكتب نقطة انطلاق، وليست بديلًا عن الموقع الرسمي لكل منحة. تحقق دائمًا من المصدر الرسمي قبل التقديم. هذه الأدلة غير مرتبطة بأي جهة منح أو جامعة، ولا تضمن قبولًا أو تمويلًا.
